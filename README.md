# ClaimTheHour

**24 hours. 24 spots. Claim yours.**

V1 is a lightweight Cloudflare Worker landing page used to validate the core product idea before adding payments and a database.

## Local development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm install
npm run deploy
```
